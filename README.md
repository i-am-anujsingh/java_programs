## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/i-am-anujsingh/java_programs.git
```

### 2. Navigate to the repository

```bash
cd java_programs
```

### 3. Explore the projects

Open the relevant project folder or Java source file in your preferred Java development environment.

For standard Java programs containing a `main()` method, compile and run them using:

```bash
javac FileName.java
java FileName
```

**Note:** The Todo List uses Java Applet technology, which is deprecated and unsupported by modern browsers and removed from current Java releases. Running it may require an older, compatible Java environment or modifications to use a modern GUI framework such as Swing or JavaFX.
